# 红果短剧 Linux v1.74.9

- “下载未完成集”改为“下载后续未完成集”：只下载点击时当前集之后尚未完成、未排队且未锁定的集数，不包含当前集和前面的集数。
- 批量提交期间防止重复点击，保持原先的剧集、起始位置和清晰度；单集提交失败不阻断其他集，并显示提交结果。
- 修正 App 取源错误被统一隐藏的问题：分别提示清晰度不足、视频尺寸无法确认、编码暂不支持、网络与接口错误。清晰度不足时显示接口返回的最高可用兼容片源尺寸。
- 部分 App 视频虽标为 1080p，实际尺寸只有 640×360；指定 1080p 时仍严格检查尺寸，不静默降级或切换到网页源。
- 播放失败时移除重复追加的“自动缓存准备失败”提示，保留实际错误原因；可点击“改用 App 最高可用画质”主动尝试现有 App 片源。
- 保持默认 H.264、前后各 5 集缓存、自动季按钮及一键原位更新。

## 验证与更新

增加后续集范围、排队/锁定过滤、重复点击、切集和切清晰度时的批量一致性、部分失败继续提交、错误原因保留及主动改用可用画质的回归检查，并验证假高清标签不会绕过尺寸要求。

发布流程通过全部 46 项播放回归、Linux 打包及完整原位更新检查后发布。可在“设置 → 检测更新”中点击“一键更新并重启”，无需卸载。首次安装下载 `hongguo-drama-1.74.9-linux-x64.tar.gz`，解压后运行 `红果短剧.sh`。
