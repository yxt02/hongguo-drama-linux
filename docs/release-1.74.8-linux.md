# 红果短剧 Linux v1.74.8

- 默认直接使用 H.264 兼容播放，覆盖新装和已有安装，不必等黑屏后再切换。转码保持源视频尺寸，复用有效兼容缓存，并串行提前准备附近集数。
- 可单独将某部剧改为自动解码，并记住选择；也能随时恢复 H.264。
- 自动从同一来源搜索其他季，识别剧名末尾的 1/2/3、一/二/三、第几季/部、Season N 和 SＮ，支持括号和全角数字。
- 剧名下方直接显示按季号排序的按钮，点击即切换，无需先手动关联。每季独立保存观看进度、下载与解码偏好。
- 标题匹配是启发式识别；过滤其他剧名、跨来源和已移除的条目，同季号不同条目保留剧名供区分。不规范标题可通过「修正季信息」手动修正。
- 自动查找在后台进行，有缓存和重复请求合并；查找失败可重试，不影响当前播放。
- 更新 README 中的使用说明和 GitHub 搜索提示；仓库描述、Topics 和下载入口已补齐。

## 验证与更新

新增默认 H.264、自动季号识别、后台查找缓存/重试和一键切季回归检查。发布流程通过全部播放回归、Linux 打包及完整原位更新检查后才发布。

已有完整目录包可在「设置 → 检测更新」中点击「一键更新并重启」，无需卸载。首次使用下载 `hongguo-drama-1.74.8-linux-x64.tar.gz`，解压后运行 `红果短剧.sh`。
