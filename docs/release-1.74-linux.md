# Linux v1.74.0

- 自动播放缓存改为磁盘文件，按当前集前后各五集保留，最多十一集。优先预取后续集，后台最多两个任务。
- 切集或切换清晰度后取消窗口外任务，清理自动缓存及其兼容副本；保留仍在读取的文件，读完后再释放。
- 关闭窗口后保留完成的磁盘缓存，重启时校验并复用。中断或损坏的文件重新准备。
- 合并“缓存下一集”“看完自动删”“兼容模式”为默认自动处理。旧的看完即删设置不再删除手动下载。
- 播放、预缓存、新建下载使用统一清晰度选择。自动模式优先 App 高清片源，再按真实尺寸选流；App 不可用时允许自动模式回退到网页。
- 指定 1080p/720p 时校验实际分辨率，不静默降级。播放器显示片源尺寸，切换画质保留播放位置及暂停状态。
- 完整视频直接写磁盘；CENC 和分段 HLS 都经过统一准备流程。自动缓存单集限制为 1GB。
- 兼容缓存增加来源、质量、原件身份和文件大小元信息，并经过 FFprobe 校验；损坏或身份不符时重建。
- 所有来源的 HLS 均支持兼容转码准备。强制重建转码副本时可复用已完成的磁盘原件。
- H.264 软件转码调整为 CRF 18，不主动缩小视频尺寸；正常解码后继续监测冻结画面，避免单凭后续暗场触发修复。

## 验证

运行完整离线回归：

```sh
npm run test:playback
```

包含真实 FFmpeg 生成 HEVC 视频、磁盘准备、H.264 转码、完整解码、可见像素验证及缓存复用；其余测试覆盖跳集、清晰度切换、任务取消、重启、损坏缓存与下载文件保留。

构建分发包：

```sh
npm run package:linux
```

高清优先仍取决于来源实际提供的版本；锐化或超分辨率不会恢复原片中已丢失的细节。
