# 红果短剧 Linux v1.74.13

- 播放和下载优先使用新版 App 取源接口。旧 App 入口只在新版接口未返回有效模型时尝试。自动画质仍选择 App 可用的最高兼容分辨率，固定清晰度按实测视频尺寸校验。
- 停用官网媒体回退。升级后，应用会在读取播放缓存时淘汰已标记的官网低清视频和 H.264 缓存。
- App 已穷尽取源路径时，单次操作不再重复取源。播放器显示实际取源错误，省去无效的转码和重复连接操作。
- 发布验证覆盖官网未公开的后续分集，通过 App 获取、播放、独立下载及 H.264 兼容检查后才发布。

已有安装可在「设置 → 检测更新 → 一键更新并重启」升级。
