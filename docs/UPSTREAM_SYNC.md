| 模块 | 同步内容与 Linux 适配 |
|---|---|
| `playback-device` | 懒建立匿名播放身份；同进程取源、下载和搜索共享一次注册。失败结果也共享，避免重试不断注册；不落盘身份或令牌 |
| `app-source` | 注册身份用于播放请求；解析当前直接 `video_list`，兼容旧备用模型；保留精确分集匹配、密钥与 HTTPS 校验 |
| `hongguo` | 当前路由结构、剧集身份检查、双详情入口、限时重试及分享 ID 解析；添加空响应/匿名会话错误分类 |
| `hongguo-search` / `hongguo-app-search` / `hongguo-app-new` | 官网搜索 API、App 搜索与近期上新补搜；主进程共用 15 秒预算，不再为正常搜索启动隐藏网页 |
| `hongguo-app-catalog` / `catalog` | App 分类和热播目录、游标缓存及官网备用；保留漫画官网入口和第三方源隔离 |
| `web-media-guard` | 官网安全 DNS 双线路、连接池与跳转校验；安全 DNS 仅在用户选择直连时启用，遵守代理设置 |
| `hema` / `xifan` | 搜索剩余时间预算和已核实的西饭标题冲突修正；旧任务仅修正显示，不改文件或记录 |
| `hls-media` | 暂存在输出所在文件系统，空间预留/并发检查、UTF-8 清单边界及取消后清理 |

继续保留 Linux 专属行为：默认 App 最高实际分辨率、指定清晰度严格校验、默认 H.264、前后各 5 集缓存、后续未完成集下载、自动季按钮、托盘、品牌图标与 GitHub 原位更新。上游其他界面、公告、平台发行和合并功能未包含在此次模块同步中。

## 验证

- 正式离线入口：`npm run test:playback`，扩展为 57 项脚本；覆盖新会话、直接/旧模型、安全边界、目录与搜索集成，以及既有 Linux 功能。
- 实网抽查：同进程共享匿名身份，最近观看三部剧均取得 1920×1080 HEVC；另用隔离临时资料运行真实主进程，红果 1920×1080 HEVC、河马 720×1280 H.264、西饭 1080×1920 H.264 完成原始准备、前三秒解码、H.264 输出、206 分段读取和手动下载。
- 媒体样本、密钥和匿名身份不提交仓库。实网检查不自动进入 CI，不以离线模拟代替实网回执；没有把这些检查当作桌面听音、窗口或长期播放的验收。
- 上游一个连接池测试依赖宿主全局 Agent 的 DNS 覆盖行为，本地超时。已将其暖连接固定到本地测试服务，保留真实防护查询及复用隔离断言，18/18 检查通过。

本地 `upstream` 远程仅跟踪 `main`。后续可先 `git fetch upstream main`，以本记录的固定提交对比新增变化，再逐项移植；本次没有把未移植功能标记为已合并。
