# Linux v1.74.4 · 默认使用 App 最高可用画质

- 红果默认播放、自动缓存和新建下载统一使用 App 源。自动模式按实际分辨率优先选择最高可用档位，兼容 H.264 / HEVC；不再为了兼容 H.264 优先选择较低分辨率。
- App 暂不可用时提示原因并允许重试，不自动回到网页低清源或旧播放接口。指定 1080P / 720P 仍按真实尺寸校验。
- 官网继续提供搜索与完整分集 ID。网页可播集数仅作为目录元数据，不截断目录，也不阻止 App 尝试后续分集；具体可播集数与画质以接口实际返回为准。
- 自动缓存记录实际媒体来源。升级时重建旧的网页、旧接口及来源不明的红果自动缓存，避免自动模式继续播放此前低清文件；已有手动下载原件保留。兼容转码缓存也按新取源策略重新校验。
- 含 1.74.3 的 App 视频 CDN 403 修复：App 媒体不发送导致拒绝访问的 Referer，重试时也不重新添加。
- 保留前后各五集自动缓存、一键更新和重启、托盘菜单与关闭行为设置。

## 验证

40/40 个核心离线回归脚本、7/7 项原生取源与目录检查，以及完整升级包验证均通过。离线回归覆盖默认 App 最高画质、App 失败不请求网页/旧播放接口、强制刷新、清晰度缓存隔离、完整分集 ID 保留，以及旧自动缓存迁移和手动文件保留。

另行检查发现历史 `src/components/check-ui-state.cjs` 的测试替身缺少当前组件依赖（如来源 hook 和视频增强 hook），无法作为有效的整体验证；该旧脚本未计入上述 40 个回归脚本。

此前 1.74.3 已通过生产播放链路实测：《纵棠》第 4 集从 App 源完整下载、处理加密封装、落盘并成功解码，实际尺寸 1080×1920，编码 HEVC。本版联网重测因自动审批服务容量故障未能执行，不能据此声称全部剧集均可播放或都提供 1080P。
