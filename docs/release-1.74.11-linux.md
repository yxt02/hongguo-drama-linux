# 红果短剧 Linux v1.74.11

- 恢复遗漏的 App 播放模型请求签名，签名绑定最终主机、查询参数、实际 POST 正文与时间戳；每次取源重试重新签名。
- 修复匿名播放设备注册失败后，失败结果被整个进程永久缓存的问题；现在等待 10 秒后重试本集即可重新建立会话。
- 播放接口返回空响应时，在独立播放请求预算内尝试更新匿名会话，并通过备用官方主机、新连接重新取源；即使会话更新处于冷却期也允许一次备用主机请求；同进程共享恢复过程，一分钟内最多更新一次，避免预缓存与下载同时反复注册。
- 匿名会话注册错误保留安全的具体原因：网络、超时、HTTP 状态、空响应、无效设备编号与接口拒绝，不再统一要求重启。
- 同步上游 4.7 会话恢复及 5.4 开发分支的播放签名、慢注册预算和备用官方主机修复，保留 App 高清优先、严格清晰度校验、App CDN 请求头修复及 Linux 专属功能。
- 发布流水线新增实网播放检查：App 取源、下载解密、三秒解码、H.264 兼容转换、播放分段读取与手动下载通过后才发布。检查不保存或输出设备身份、播放地址和解密密钥；抽查结果不代表所有剧集长期可用。

已有安装可在“设置 → 检测更新 → 一键更新并重启”升级，无需卸载。
