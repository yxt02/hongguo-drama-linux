# Linux v1.74.1 · 一键更新，无需卸载重装

- 设置 → 检测更新 → **一键更新并重启**：一次点击完成检查、下载、校验、退出替换及重新启动，不必再手动安装。下载期间可取消；检查更新提醒仍可关闭。
- 修正 Linux 更新来源，使用 `yxt02/hongguo-drama-linux` 正式发行版，正确识别 `vX.Y.Z-linux` 标签。Mac/Windows 保留上游检查来源。
- 安装前核对 SHA256、归档路径、文件类型、大小和程序内部版本。校验失败不替换旧版；目录替换失败恢复旧版，成功后保留一份 `.previous` 备份。
- 设置、观看记录及程序目录外的手动下载保留，桌面入口和命令行入口路径不变。
- 终端可使用 `hongguo --update --restart`，更新器使用内置 Electron/Node 运行时，无需另装 Node.js。
- 首次接入：退出旧版，运行新版解压目录内的 `升级现有安装.sh`，直接使用本地文件升级原安装，无需卸载或再次下载。默认目录 `~/.local/opt/hongguo-drama`，自定义目录可设置 `HONGGUO_INSTALL_DIR`。
- 修复更新器在真实 Electron 运行时下对 ASAR 文件读取与复制的兼容问题。
