# 红果短剧 Linux v1.74.7

新增同一部剧的多季关联与切换。

- 播放器标题旁新增「关联 / 管理季」与「切换季」下拉框。
- 支持从剧库候选、同来源搜索结果或分享链接 / 剧集 ID 关联其他季。
- 可自定季号、调整季号或解除错误关联；解除不会删除下载文件或观看记录。
- 各季独立保留集数、播放位置、下载和兼容解码偏好。切季时保存当前进度，并接着目标季上次位置；未看过的季从首个可播集开始。
- 关联持久保存在本机，刷新剧集资料或重启后保留。

目前来源没有可靠的官方季关系字段，同名和标题中的季号只用于提示候选，需确认后才关联。只允许关联同一来源的剧集。

## 更新

已安装完整 Linux 目录包的用户可在「设置 → 检测更新」点击「一键更新并重启」，无需卸载。

首次安装：下载 `hongguo-drama-1.74.7-linux-x64.tar.gz`，解压后运行 `红果短剧.sh`。可运行 `install.sh` 添加到应用菜单。
