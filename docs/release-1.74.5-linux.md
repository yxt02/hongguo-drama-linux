# Linux v1.74.5 · 整剧兼容解码与预转码

- 检测到黑屏有声、无画面或解码错误后，首次转换为 H.264 兼容格式成功，会在本机记住这部剧的兼容解码方式。后续分集直接使用兼容格式，跳过每集重复失败后再回退的过程；退出重开仍生效。
- 网页/网络加载失败不作为解码故障。转换失败、被取消或过期的结果不会写入整剧偏好；不同剧集的偏好互相独立。
- 播放器显示“本剧：兼容解码 · 恢复自动”，可以清除此偏好。当前已准备的视频继续播放，下次切集或重试恢复自动判断。
- 在当前集前后各五集的缓存窗口内，优先向后串行预处理兼容视频，最多一个后台转换任务。前台进入同一集时复用主进程已有的转换任务与缓存；手动下载原件保留。
- 跳集、切剧、改清晰度、恢复自动及退出时取消不再需要的后台任务；主进程拒绝已经离开缓存范围的延迟后台转换请求。
- 包含 1.74.4 的默认 App 最高可用画质、旧网页自动缓存迁移，以及 1.74.3 的 App 视频 CDN 403 修复。不会自动切回网页低清源。
