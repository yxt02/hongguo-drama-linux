# 红果短剧 Linux v1.74.10

- 修复红果 App 取源请求返回 HTTP 200 空正文，导致在线播放、自动缓存、下载和兼容解码一起失败的问题。
- 同步原上游 4.2 的匿名播放会话恢复：同进程共享平台注册身份，适配当前直接视频模型并兼容旧模型；不登录账号，不保存身份、设备令牌或 Cookie。
- 默认仍选 App 最高实际分辨率；保留 1080p/720p 严格校验、H.264 兼容播放和前后各 5 集缓存。
- 同步 App 分类/热播目录、官网搜索 API、App 搜索及近期上新补搜、双详情入口与剧集身份检查。来源错误分别提示空响应、会话失败、网络问题和清晰度不足。
- 同步河马/西饭搜索超时预算、西饭已核实标题冲突、官网安全 DNS 与连接隔离、HLS 暂存和磁盘空间处理；官网安全 DNS 遵守用户代理选择。
- 保留后续未完成集下载、自动季切换、Linux 托盘、独立仓库图标与一键更新。具体同步范围见 [上游同步记录](UPSTREAM_SYNC.md)。

## 验证与更新

离线回归扩展为 57 项脚本。发布流程还会执行 Linux 打包与完整原位更新检查，通过后发布。

实网验证恢复了最近观看三部剧的 1080p 片源；红果、河马、西饭各一集通过真实主进程的下载准备、原视频解码、H.264 输出及播放协议分段读取。检查使用独立临时资料，未修改用户原有记录；测试抽查不代表所有作品或长期播放均已验证。

已有完整目录安装可在“设置 → 检测更新”点击“一键更新并重启”，无需卸载。首次安装下载 `hongguo-drama-1.74.10-linux-x64.tar.gz`，解压后运行 `红果短剧.sh`。
