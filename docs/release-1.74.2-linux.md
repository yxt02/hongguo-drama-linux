# Linux v1.74.2 · 托盘菜单与完整退出

- 增加系统托盘图标。菜单提供“显示主窗口”“最小化到托盘”“点 X 时”关闭行为选择及“退出程序”。点击图标可恢复主窗口。
- 设置页增加“窗口与托盘”，可选点 X 退出程序（默认）或最小化到托盘，立即保存；保留“普通最小化”和明确的“退出程序”按钮。
- 修复主窗口关闭后，隐藏搜索窗口仍存活，导致程序未退出、更新被阻止的问题。
- 完整退出时停止派发新任务、取消下载/缓存/转码、等待文件写入和 FFmpeg 收尾，再关闭窗口与托盘。中断下载保留为等待中，重启后继续调度。
- 一键更新调用相同的完整退出流程，不会被“关闭到托盘”拦截。更新器还会等待该安装的 Chromium 子进程退出。
- 首次升级脚本 `升级现有安装.sh` 会关闭指定安装的旧版及后台进程后再升级，不需要卸载或重复下载；不会按进程名称关闭其他安装。
- 支持 `hongguo --quit` 请求退出已运行的新版。系统托盘不可用时不会把窗口隐藏到不可访问的状态。

## 验证

40 个离线回归脚本通过。新增测试覆盖关闭行为持久化、托盘菜单、隐藏辅助窗口导致的退出问题、重复退出不跳过任务收尾、更新退出、托盘不可用回退、界面操作及只结束指定安装进程。

另在实际 Linux 桌面会话中使用内置 Electron 运行时验证托盘创建、隐藏主窗口、保留后台窗口及完整退出；测试资料隔离在临时目录。完整发行包原位升级测试验证校验、旧版备份、启动入口和观看记录保留、首次升级及后台退出等待。

```sh

npm run package:linux
node scripts/check-linux-update-bundle.cjs
```

托盘图标的位置及点击方式由桌面环境决定，需要桌面提供托盘服务。本版保留 1.74.1 的一键更新和 1.74.0 的缓存/解码改进。
